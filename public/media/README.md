# Медиа файлууд

Энэ фолдерт дараах нэртэй файлуудыг байршуулбал урилгын хуудас
автоматаар тэдгээрийг ашиглана (файл байхгүй бол одоогийн CSS
дэвсгэрүүд хэвээр ажиллана — юу ч эвдэрэхгүй):

| Файлын нэр           | Зориулалт                                  | Санал болгох хэмжээ / формат            |
|-----------------------|---------------------------------------------|------------------------------------------|
| `hero.mp4`             | Эхний drone hero видео (гэр, тал нутаг)     | 1080x1920 (mobile-first), 8–15 сек, mute |
| `hero-poster.jpg`      | hero.mp4 ачаалагдах хүртэлх зураг            | 1080x1920                                |
| `name-texture.jpg`     | Нэрийн reveal хэсгийн зөөлөн дэвсгэр зураг   | 1600x1600, бүдэг/зөөлөн өнгөтэй байх     |
| `gallery-1.jpg` ... `gallery-4.jpg` | Gallery-н polaroid зурагнууд   | 800x800 (square)                         |
| `ambient.mp3`          | Дэвсгэр хөгжим (морин хуур, байгалийн дуу)  | 1–3 минут, loop хийхэд тохиромжтой       |

## AI-аар зураг/видео гаргах

Дараах prompt-уудыг Midjourney, GPT Image, Runway, Kling зэрэгт ашиглаж болно:

- **hero**: "Traditional Mongolian ger on golden steppe, drone aerial shot, sunset, cinematic, warm tones, 8K"
- **name-texture**: "Soft warm smoke drifting, cream and gold tones, minimal abstract, cinematic bokeh"
- **gallery**: тус тусад нь "ger interior warm light", "horses running steppe sunset", "mountains Khövsgöl golden hour", "traditional Mongolian ornament close-up"

Зурагнуудаа гаргаад энэ фолдерт яг дээрх нэрээр хуулж тавихад л хангалттай.
